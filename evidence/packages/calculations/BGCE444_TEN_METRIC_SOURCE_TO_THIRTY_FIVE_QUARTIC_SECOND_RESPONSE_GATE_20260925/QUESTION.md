# BGCE444 question — ten metric sources to thirty-five quartic coefficients

## Primary question

BGCE290/BGCE291 retain an exact rank-ten source solder

\[
S:A_{10}\longrightarrow \operatorname{Sym}^2(V_4^*)
\]

from the ten independent doubled metric sources.  Does the coefficient-free
quadratic response

\[
Q(a)=\operatorname{Sym}_4\bigl(S(a)\otimes S(a)\bigr)
\]

have a second differential of exact rank 35, with the whole 20-dimensional
complement retained, in every one of the eight source sectors?

## Strong physical question

Does that algebraic second response already equal the **actual** thirty-five
UB612 PBM `U4` coefficient response, so that it predicts those coefficients
from the ten Braid sources rather than merely providing a carrier capable of
representing them?

## Pass and stop rules

- Algebraic scoped PASS: the exact source-fixed map has rank 35, kernel
  dimension 20, and sector/refinement typing does not require a fitted
  coefficient.
- Physical bridge PASS: the committed UB612 lineage contains the actual
  55-column second source-response map and it agrees with the source map
  before the `U4` target values are used to define a lift.
- Stop physical promotion if UB612 contains only the already reported four
  root first derivatives, if an actual ten-source second response is absent,
  or if the `U4` values must be read first to define their source preimage.

No Einstein equation, Einstein-Hilbert/Fierz-Pauli action, MMR/CGR, manual
`3/5`, target matching, or coefficient fit is allowed.
